# Soulpals｜灵伴 AI 数字家人官网

灵伴是一款有记忆、懂情绪、能陪伴的 AI 数字家人产品。本项目为产品 Landing Page 官网源码。

## 页面内容

- 产品定位：从一次问答升级为持续关系
- 长期记忆、情绪理解与主动陪伴
- 灵伴智能体中枢架构
- 数字人表达、实体设备与家庭服务
- 安全、隐私与常见问题

## 本机运行

环境要求：Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

启动后在浏览器打开终端显示的本地地址，通常为 `http://localhost:5173`。

## 主要文件

- `app/page.tsx`：页面内容与结构
- `app/globals.css`：视觉样式与移动端适配
- `app/layout.tsx`：页面标题及基础布局

## 构建

```bash
npm run build
```
